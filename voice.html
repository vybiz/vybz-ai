VYBZ Voice Lab

Be clear on what this is

Cloning a voice to sing needs a singing voice conversion model (for example RVC-based tools such as Applio) running on a GPU. That can't run in a free web page, so this guide walks you through doing it outside VYBZ for free. Only use your own voice. Never clone another person or artist. Check each tool's own license before commercial use.
